# river-solus

Solus `.eopkg` recipe for [River](https://codeberg.org/river/river), a non-monolithic Wayland compositor.

Only `river/package.yml` and `river/MAINTAINERS.md` are maintained by hand. Everything else (`pspec_x86_64.xml`, `abi_*`, `.eopkg`) is generated by `solbuild` on each build.

## Package

| Package | Description | License | Version |
| :--- | :--- | :---: | :---: |
| **river** | Non-monolithic Wayland compositor | GPL-3.0-only | 0.5.0 |

## Building

```bash
cd river
sudo solbuild build package.yml
```

This generates `river-0.5.0-1-1-x86_64.eopkg` and `river-devel-0.5.0-1-1-x86_64.eopkg` plus the `pspec_x86_64.xml` and `abi_*` metadata.

## Installation

```bash
sudo eopkg it ./river-0.5.0-1-1-x86_64.eopkg
```

River needs a window manager implementing the `river-window-management-v1` protocol (e.g. `tinyrwm`) and an init script to be useful.
